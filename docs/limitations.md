# Limitations

- Definitions use a small JSON model rather than BPMN XML or a vendor-specific low-code export.
- The path simulator evaluates the documented example rules; it does not execute arbitrary expressions or external service calls.
- Generated reports are review artifacts and do not prove deployment to an automation platform.
- The repository has no hosted demo because its primary interface is a deterministic command-line workflow.
- Security checks cover dependency advisories and input validation; they do not constitute a formal security assessment.
